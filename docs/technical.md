# RU напрямую

Нативное приложение macOS с одним переключателем и постоянной фоновой службой. При включении новые соединения к `.ru` и поддоменам идут через Wi-Fi. Основной маршрут остаётся под управлением существующего hidemy.name/OpenVPN.

## Использование

1. Откройте `RU напрямую.app` и нажмите «Установить и включить».
2. Подтвердите системный запрос macOS. Приложение установится в `/Applications`, фоновая служба — в launchd.
3. Дождитесь статуса «Работает». После первой установки один раз перезапустите Chrome: соединения, открытые до установки, не переносятся между сетями. При последующих переключениях уже открытые соединения сторонних программ также могут потребовать переподключения.
4. Кнопка «Выключить» возвращает прежние параметры DNS macOS и Chrome. hidemy.name продолжает работать самостоятельно.

Служба запускается при загрузке Mac и сохраняет выбранное состояние. Интерфейс запускается при входе пользователя; закрытие окна не выключает службу. Если выключить режим, после перезагрузки он останется выключенным.

## Границы поведения

- Правило относится к DNS-именам с окончанием `.ru`, включая произвольное число поддоменов. `.рф`, `.ru.com`, другие домены и ресурсы сайта на `.net`/`.com` не входят в него.
- Поддерживаются системный DNS macOS и Chrome с параметрами DNS, которые служба применяет на время работы. Произвольное приложение со своим скрытым DNS, встроенным прокси/VPN или ранее сохранённым реальным IP может обойти доменную классификацию.
- Потеря Wi-Fi не включает VPN как запасной выход для распознанных `.ru`. IPv6-only сайты недоступны, если прямое подключение Wi-Fi не поддерживает необходимый адресный протокол. Эта версия разрешает прямые назначения по IPv4.
- Сервис не подключает и не отключает hidemy.name и не заменяет его Kill Switch. Если сам VPN отключён, обычный трафик следует системным маршрутам; интерфейс показывает это состояние отдельно.
- Выключенный режим оставляет небольшой движок для обработки уже закэшированных виртуальных адресов по обычному маршруту. Это предотвращает поломку вкладок при переключении.
- Chrome может показывать управление настройками: служба временно задаёт только `DnsOverHttpsMode` и `BuiltInDnsClientEnabled`. Исходный файл сохраняется. Внешние изменения не перезаписываются молча.

## Устройство и восстановление

Локальный DNS выдаёт для `.ru` отдельные FakeIP-адреса. TUN захватывает только `198.19.0.0/16` и `fd7a:7275:7769::/48`, без второго default route. Выход `.ru` привязан к аппаратному Wi-Fi. DNS к upstream Cloudflare передаётся по HTTPS. Более широкие reject-маршруты блокируют виртуальные адреса при падении движка. Движок контролируется отдельной launchd job; при загрузке Mac служба сначала создаёт защитные маршруты и только затем запускает движок.

Настройки и кэш службы: `/Library/Application Support/RUWiFi`.
Пользовательское состояние: `~/Library/Application Support/RUWiFi/preferences.json`.
Автозапуск службы: `/Library/LaunchDaemons/local.matvey.RUWiFi.Service.plist`.
При наличии известной старой службы `com.codex.eis-split-tunnel` установщик проверяет точный хеш её скрипта и параметры launchd, затем отключает её и удаляет только маршруты из её журнала, совпадающие с текущим Wi-Fi. Её скрипт и plist сохраняются; снимок удалённых маршрутов записывается в `legacy-retired.json`. Неизвестная версия старой службы останавливает автоматический перенос с ошибкой.

Автозапуск интерфейса: `~/Library/LaunchAgents/local.matvey.RUWiFi.Login.plist`.

Интерфейс читает поколение настроек, время последней проверки и хеш установленной службы. Применение DNS выполняется только после готовности движка. Журнал восстановления записывается до изменения файлов. Чужие изменения и символические ссылки приводят к ошибке вместо перезаписи.

## Сборка и проверки

Из корня репозитория: `./app/build.sh`. Скрипт использует Swift Command Line Tools, Python 3 и Go. Исходники движка находятся в `vendor/sing-box`: версия 1.14.2 (коммит `af6e64c3b69e6132ebaee0e1a3d24e93903f6709`) с исправлением устойчивости FakeIP-кэша к аварийному завершению. Курсор выделения адресов сохраняется синхронно перед выдачей адреса; при старте метаданные не удаляются. Сборка движка помечена `1.14.2-ruwifi.1`; лицензия GPLv3 приложена.

`CoreTests.swift`: границы доменов, изоляция маршрутов, начальный маршрут при восстановлении, переключение, актуальность статуса.
`InstallTests.swift`: первая установка, сохранение выключенного состояния при обновлении, автозапуск интерфейса.
`StorageTests.swift`: безопасное чтение, атомарная запись, восстановление, внешние изменения и права файлов.
`integration_test.py`: настоящий движок в отдельном процессе без системного TUN; DNS `.ru`, вложенные имена, отсутствие обходящих IP-подсказок HTTPS, переключение выхода и HTTPS через Wi-Fi. Также проверяются перезапуск, аварийное завершение с сохранением FakeIP и отказ без запасного выхода при отсутствии указанного Wi-Fi. Временный процесс всегда завершается.

Системные проверки после установки выполняются отдельно: реальные браузеры, `.ru`/обычный выход, on/off, перезапуск службы и автозапуск. Модульные тесты не подтверждают физический сон или перезагрузку ноутбука.
