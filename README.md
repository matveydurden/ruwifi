# RU напрямую · RUWiFi

**Один переключатель: `.ru` через Wi-Fi, остальной трафик — по маршрутам вашего VPN.**

RUWiFi — приложение для macOS, которое работает рядом с уже установленным VPN. Это универсальный подход без привязки к VPN-провайдеру: не нужны его API, подписка внутри RUWiFi или импорт ключей. Приложение автоматически распознаёт домены `.ru` и поддомены любой глубины и направляет новые соединения к ним напрямую через Wi-Fi.

**Совместимость со всеми VPN не гарантируется.** Проверено с **hidemy.name 2.2.6 / OpenVPN**. Другие клиенты могут работать, если используют системные маршруты macOS и разрешают прямой выход через Wi-Fi. Kill Switch, собственный DNS или прокси могут мешать работе — подробности ниже.

## Требования

- **macOS 15 или новее, Apple Silicon** (M1 и новее). Готовых сборок для Intel, Windows и Linux нет.
- Подключение к интернету через **Wi-Fi** и права администратора для установки фоновой службы.
- Уже установленный и отдельно подключённый VPN, если остальной трафик должен идти через него.

## Скачать с GitHub и установить без Terminal

[**Скачать RUWiFi 1.0.3 для Apple Silicon**](https://github.com/matveydurden/ruwifi/releases/download/v1.0.3/ruwifi-macos-arm64.zip)

1. Распакуйте ZIP и откройте **«RU напрямую.app»**. При обновлении сначала закройте старый интерфейс через **⌘Q** — фоновая служба продолжит работать.
2. Нажмите **«Установить и включить»**. На первой установке режим включится; обновление сохраняет прежнее состояние переключателя.
3. Подтвердите права администратора в **системном окне macOS**. Пароль в Terminal вводить не нужно. Установка перенесёт приложение в `/Applications` и настроит автозапуск.
4. После установки запускайте приложение из **«Программ»**. Включение и выключение не требуют пароля. Обновление системной службы может запросить разрешение снова.

Для этого сценария Codex и автоматическое управление экраном не нужны. Приложение пока подписано локально, без нотариализации Apple: macOS может заблокировать первый запуск. Если вы доверяете загруженному релизу, используйте предусмотренное macOS разрешение для этого приложения в «Системные настройки → Конфиденциальность и безопасность»; [инструкция Apple](https://support.apple.com/102445). Отключать Gatekeeper не требуется.

Скачать приложение можно без прав администратора; установка службы, которая меняет системную сеть, требует отдельного разрешения macOS.

## Установка одной командой

Откройте **Terminal** и вставьте:

```bash
( f="$(mktemp)" && trap 'rm -f "$f"' EXIT && curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/matveydurden/ruwifi/v1.0.3/install.sh -o "$f" && /bin/bash "$f" )
```

Подтвердите права администратора **в стандартном окне macOS**. Пароль в Terminal вводить не нужно. **GitHub-аккаунт, Homebrew, GitHub CLI, Go и Xcode для установки не нужны.**

Установщик скачает готовый закреплённый релиз, проверит SHA256, целостность подписи и версию, установит **«RU напрямую»** в `/Applications`, настроит фоновую службу и автозапуск интерфейса. При первой установке режим включён; при обновлении сохраняется ваше состояние Вкл/Выкл.

После первой установки полностью закройте Chrome через **⌘Q** и откройте снова, предварительно сохранив работу. Подключите свой VPN. Откройте «RU напрямую» и дождитесь статуса **«Работает»**.

### Обновление и предварительная проверка

Для обновления возьмите команду установки из актуальной версии этого README. Для замены системной службы macOS может снова запросить подтверждение в своём окне.

Чтобы только скачать и проверить сборку **без установки и изменения сети**:

```bash
( f="$(mktemp)" && trap 'rm -f "$f"' EXIT && curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/matveydurden/ruwifi/v1.0.3/install.sh -o "$f" && /bin/bash "$f" --check )
```

Релизы и контрольные суммы: [GitHub Releases](https://github.com/matveydurden/ruwifi/releases).

## Как пользоваться

Откройте **«RU напрямую»** в «Программах» или нажмите **`.ru`** в строке меню.

| Действие | Результат |
| --- | --- |
| **Включить** | Новые распознанные соединения к `.ru` направляются через Wi-Fi. Остальные адреса используют обычные системные маршруты. |
| **Выключить** | Возвращаются прежние настройки DNS macOS и Chrome; трафик идёт по обычным маршрутам. |
| Закрыть окно | Фоновая служба продолжает работать в выбранном режиме. |
| Войти в macOS | Открывается фоновый интерфейс; выбранное состояние сохраняется. |
| Потерять Wi-Fi | Распознанные `.ru` ждут Wi-Fi, не переключаясь на VPN как запасной выход. |

Служба настроена на запуск при загрузке Mac. Выключенный режим оставляет небольшой движок для уже закэшированных виртуальных адресов, чтобы переключение не ломало открытые вкладки. Сам VPN приложение не включает и не выключает. Если VPN отключён, обычный трафик следует доступному системному маршруту.

## Совместимость и границы

| Ситуация | Что поддерживается |
| --- | --- |
| `site.ru`, `www.site.ru`, `a.b.c.site.ru` | Включены в правило без списков сайтов и ручного добавления. |
| `.рф`, `site.ru.com`, ресурсы сайта на `.com` и других доменах | Не включены в правило `.ru`. |
| hidemy.name 2.2.6 / OpenVPN | Проверены реальные соединения и страницы браузера. |
| Другие VPN с системным туннелем macOS | Подход не зависит от марки клиента; нужна проверка с конкретным VPN и его настройками. |
| VPN с Kill Switch или запретом трафика вне туннеля | Прямой выход может блокироваться. RUWiFi не обходит и не отключает эту защиту. |
| Приложение со своим DNS/DoH, прокси, встроенным VPN, ECH или сохранённым реальным IP | Доменная классификация может быть обойдена; обещания «абсолютно все приложения» нет. |
| IPv6-only сайт | Не поддерживается: прямые назначения этой версии разрешаются по IPv4. |

Поддерживаются системный DNS macOS и Chrome с параметрами DNS, которые временно применяет служба. Chrome может показывать управление настройками; исходные параметры восстанавливаются при выключении. Внешние изменения не перезаписываются молча. Уже открытые соединения иногда требуют переподключения.

Индикатор **«VPN обнаружен»** использует список соединений macOS и маршрут к контрольному IP. Это подсказка о туннеле, а не доказательство, что любой сайт идёт через VPN. Проверяйте фактический выход для важных адресов.

Сборка имеет локальную подпись **без Developer ID и нотариализации Apple**. Проверка подписи подтверждает целостность, а не сертификацию Apple. Установщик не отключает Gatekeeper. Поддерживается установка для одного пользователя Mac. Физический сон/пробуждение и перезагрузка пока отдельно не проверены.

## Если что-то не работает

1. Проверьте, что Wi-Fi подключён, VPN включён отдельно, а режим RUWiFi включён.
2. Дождитесь применения состояния. Интерфейс читает статус каждые 250 мс. Статус основан на локальном DNS, маршрутах и работе службы — проверки Яндекса или других внешних сайтов не выполняются. «Работает» не означает проверенную доступность интернета.
3. Если установили приложение впервые, сохраните работу и полностью перезапустите браузер.
4. Нажмите **«Скопировать диагностику»**. Перед публикацией просмотрите её: пути и сведения о сети могут быть личными.
5. При конфликте с VPN выключите RUWiFi его кнопкой, чтобы восстановить прежние настройки. Не удаляйте фоновые службы вручную во время работы.

HTTP 403, CAPTCHA или ошибка сервера сами по себе не означают ошибку маршрута. Проверка IP через обычный домен показывает обычный выход; она не доказывает выход `.ru` через Wi-Fi. [Техническое устройство и восстановление](docs/technical.md).

## Разработка

Нужны macOS 15+, Apple Silicon, Swift Command Line Tools, Python 3 и Go 1.25.5+. Интеграционные проверки используют локальный сервер и не открывают внешние сайты.

```bash
git clone https://github.com/matveydurden/ruwifi.git
cd ruwifi
./app/build.sh
python3 tests/test_installer.py
```

Результат: `dist/RU напрямую.app`. Сборка запускает тесты Swift, проверку конфигурации и интеграционные тесты настоящего движка с локальным сервером, без внешних сайтов и изменения системных маршрутов и DNS. `./scripts/package.sh` также создаёт архив, `SHA256SUMS` и обновляет закреплённую сумму в `install.sh`. Версию в `app/Info.plist` и `install.sh` обновляют вместе перед выпуском.

Swift-исходники: `app/`. Движок: `vendor/sing-box/`, версия **1.14.2**, исходный коммит `af6e64c3b69e6132ebaee0e1a3d24e93903f6709`. Локальное исправление устойчивости FakeIP-кэша: [патч](docs/sing-box-fakeip.patch). Бинарник обозначен `1.14.2-ruwifi.1`.
