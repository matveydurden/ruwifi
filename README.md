# RU напрямую · RUWiFi

Приложение для **macOS 15+ на Apple Silicon (M1/M2/M3/M4 и новее)**. Один переключатель: `.ru` и любые его поддомены идут напрямую через Wi-Fi; остальные адреса следуют обычному маршруту, которым управляет ваш VPN.

Разработано и проверено с **hidemy.name 2.2.6 / OpenVPN**. VPN включается отдельно. Репозиторий и готовые релизы приватные.

## Установка через терминал

Нужен [GitHub CLI (`gh`)](https://cli.github.com/) с доступом к этому репозиторию. Если `gh` уже установлен и выполнен вход, **скопируйте одну команду**:

```bash
( f="$(mktemp)" && trap 'rm -f "$f"' EXIT && gh api repos/matveydurden/ruwifi/contents/install.sh -H 'Accept: application/vnd.github.raw' > "$f" && /bin/bash "$f" )
```

Введите пароль администратора **Mac**, когда Terminal попросит его. Символы пароля не отображаются — это нормально. Команда скачает готовую сборку, проверит SHA256 и целостность подписи, установит приложение и фоновую службу, настроит автозапуск и откроет окно. **Go, Xcode и сборка из исходников для установки не нужны.**

После первой установки один раз полностью закройте Chrome через **⌘Q** и откройте снова. Подключите hidemy.name и дождитесь в приложении статуса **«Работает»**.

### Если `gh` ещё нет

При установленном [Homebrew](https://brew.sh/) выполните:

```bash
brew install gh
gh auth login --hostname github.com --web
```

Войдите в GitHub-аккаунт с доступом к приватному `matveydurden/ruwifi`. Затем выполните команду установки выше. Без Homebrew можно установить `gh` по инструкции на [cli.github.com](https://cli.github.com/).

### Обновление

Повторите ту же команду установки. Ранее выбранное состояние **Вкл/Выкл сохраняется**. Для обновления службы снова может потребоваться пароль администратора Mac.

Проверить только скачивание и целостность, без установки и изменения сети:

```bash
( f="$(mktemp)" && trap 'rm -f "$f"' EXIT && gh api repos/matveydurden/ruwifi/contents/install.sh -H 'Accept: application/vnd.github.raw' > "$f" && /bin/bash "$f" --check )
```

## Как пользоваться

- Откройте **«RU напрямую»** в «Программах» или нажмите `.ru` в строке меню.
- **Включить** — новые соединения к `.ru` идут через Wi-Fi. **Выключить** — возвращаются прежние настройки DNS и Chrome, трафик снова следует обычному маршруту.
- Служба запускается при загрузке Mac; окно — при входе пользователя. Выбранное состояние сохраняется. Закрытие окна или выход из интерфейса не выключают службу.
- При потере Wi-Fi распознанные `.ru` не переключаются на VPN как запасной выход. Интерфейс показывает ожидание сети.

## Что учитывать

- Правило относится к окончанию `.ru`: `site.ru`, `www.site.ru`, `a.b.site.ru`. `.рф`, `.ru.com` и ресурсы того же сайта на других доменах в правило не входят.
- Поддерживаются системный DNS macOS и Chrome с настройками, которые применяет служба. Приложения со своим зашифрованным DNS, прокси или сохранёнными реальными IP могут обойти классификацию. Уже открытые соединения могут требовать переподключения.
- Прямые назначения разрешаются по IPv4. Сайты, доступные только по IPv6, этой версией не поддерживаются.
- Chrome может показывать управление настройками: служба временно меняет только параметры DNS и возвращает их при выключении.
- Сборка подписана локальной подписью, без нотариализации Apple. Установщик проверяет её целостность и закреплённый SHA256; это не Developer ID. Он не отключает Gatekeeper.
- Поддерживается установка для одного пользователя Mac. Другие VPN и Intel Mac не проверены. Физическая перезагрузка и сон/пробуждение пока отдельно не проверялись.

Если установка сообщает об ошибке, повторите команду после устранения указанной причины. При ошибке работы откройте приложение и нажмите **«Скопировать диагностику»**. Это состояние службы, не обещание доступности каждого сайта: ошибки самого сайта и блокировки его серверов возможны при исправном маршруте.

## Исходники и сборка

Готовые сборки: [Releases](https://github.com/matveydurden/ruwifi/releases). Установка выше использует закреплённый релиз и его контрольную сумму.

Для разработки нужны macOS 15+, Swift Command Line Tools, Python 3 и Go 1.25.5+. На Mac с подключённым Wi-Fi:

```bash
gh repo clone matveydurden/ruwifi
cd ruwifi
./app/build.sh
```

Результат: `dist/RU напрямую.app`. Скрипт запускает тесты Swift, проверку конфигурации и интеграционные проверки настоящего движка в отдельном процессе, без изменения системных маршрутов/DNS. `python3 tests/test_installer.py` проверяет отказ при ошибке скачивания и повреждённом архиве. `./scripts/package.sh` пересобирает приложение, создаёт архив, `SHA256SUMS` и обновляет закреплённый SHA256 в `install.sh` для следующей публикации.

Swift-исходники: `app/`. Полные исходники используемого движка: `vendor/sing-box/`, версия **1.14.2**, исходный коммит `af6e64c3b69e6132ebaee0e1a3d24e93903f6709`. Локальное исправление устойчивости FakeIP-кэша: [патч](docs/sing-box-fakeip.patch). Бинарник обозначен `1.14.2-ruwifi.1`.
